Support

Work through a connection issue.

Start with the point where setup stops. This guide covers the iPhone and iPad preview on your home network.

Finding and pairing your console.

My console does not appear automatically.

Automatic discovery is not included in the iPhone and iPad preview. Add the console manually using its current local address. Confirm that the device and console can reach each other on the same network and that Remote Play is enabled.

The Account ID is rejected.

The registration form requires the Account ID for the console account in Base64 form that decodes to eight bytes. It does not accept an online name or email address as the Account ID. The app cannot look up this value or sign in to PSN.

The pairing code is rejected or has expired.

Open Link Device or Add Device on the console again, then enter the current eight-digit code in GameRemote. Check that you are registering the intended console and account. A console user's four-digit login PIN is a separate value.

Local Network access was denied.

Review GameRemote's Local Network permission in your device's Settings and allow access before retrying. Return to the app and try the local connection again. If it still fails, include the permission state in your support report.

Video, sound and input.

The connection fails after registration.

Check that the console is available, Remote Play remains enabled and the saved address is still its current local address. Keep both devices on the same reachable home network. Record the error message and where the connection stops.

Physical iPhone/iPad playback and reconnect behaviour have not yet been verified. A failed session may require an app fix as well as a network check.

Playback is delayed, interrupted or out of sync.

Check the connection between your device, console and home network. Congestion or an unstable link can affect playback. The preview targets 720p at 60 fps using H.264; it has no video-quality picker and does not guarantee frame rate or latency.

A controller function does not work.

Confirm that the controller is paired with your device. The iPhone and iPad preview includes basic paired game-controller input and on-screen controls. Touchpad swipes, motion input, rumble, adaptive triggers and microphone input are not included. Physical controller compatibility has not yet been verified.

Still unable to connect?

Record the error, app version, device, console model and steps that reproduce the issue. Keep all pairing credentials private.

Contact GameRemote support

For Mac builds, include your macOS version and the connection method you used.
