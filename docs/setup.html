Support

Set up your local connection.

A guide to the current GameRemote preview on iPhone and iPad.

Before you begin.

  • A compatible PS5 or PS4 you own or are authorised to use, with Remote Play enabled.
  • Your iPhone or iPad and the console on the same reachable home network.
  • Access to the console's Link Device or Add Device screen and the Account ID for the console account.

Pre-release guide. These steps describe the current app interface. Pairing, playback and controller input on physical iPhone and iPad hardware have not yet been verified.

Pair your console.

  1. Enable Remote Play.

    Turn on Remote Play in your console's settings. Keep the console available on the same home network as this device.

  2. Open the console's pairing screen.

    Use Link Device or Add Device to display the current eight-digit pairing code. Leave this screen available while you register.

  3. Add the console address.

    In GameRemote, choose the add button or Connect manually. Enter your console's local address and select its console type. The iPhone and iPad preview does not automatically discover consoles.

  4. Enter the Account ID and pairing code.

    Use the PSN Account ID in Base64 form for the selected console account. It must decode to eight bytes. Enter the current eight-digit console pairing code, then choose Register console.

    The app cannot look up your Account ID or sign in to PSN. If you do not have the required Account ID, pairing cannot be completed in this version. An online name or email address will not work in this field.

  5. Allow local-network access.

    Allow GameRemote to reach your console when your device asks for Local Network permission. If access was denied, review the permission in the device's Settings before trying again.

  6. Connect and check your controls.

    Select the registered console and connect. If a four-digit console user login PIN is requested, it is separate from the eight-digit pairing code. Use on-screen controls or a game controller paired with your device.

Know the current limits.

The iPhone and iPad preview uses a fixed 720p, 60 fps target with H.264. Basic touch controls and paired game-controller input are included. Touchpad swipes, motion input, rumble, adaptive triggers and microphone input are not included.

Use your home network. Performance depends on the console, device and connection, and the stream profile is a target. Internet setup and automatic console discovery are not supported in this preview.
