# GameRemote

An open-source, unofficial remote-play client for your own PlayStation console.

GameRemote for iPhone, iPad and Mac is being prepared for release. There is no public store download yet. This repository hosts the support website and will carry reviewed source snapshots; it does not contain private build history or signing material.
