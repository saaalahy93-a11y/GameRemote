# Licence and documentation provenance

GameRemote derives from [chiaki-ng](https://github.com/streetpea/chiaki-ng), which
builds on the original [Chiaki](https://git.sr.ht/~thestr4ng3r/chiaki) project.
The source licence remains [AGPL-3.0-only](../COPYING), with the existing
[OpenSSL additional permission](../LICENSES/AGPL-3.0-only-OpenSSL.txt).
The [existing derivative and third-party notice](prototype/NOTICE.md) preserves
additional attribution, component notices and source requirements.

## Inherited documentation

The inherited documentation was authored for the upstream application. Its
last source revision in this checkout is
`a9a2805884cfa83865fdfcc09ca3ddfcd628aa42`. The original guides remain available in
that [upstream source tree](https://github.com/streetpea/chiaki-ng/tree/a9a2805884cfa83865fdfcc09ca3ddfcd628aa42/docs):

- [Setup and configuration](https://github.com/streetpea/chiaki-ng/tree/a9a2805884cfa83865fdfcc09ca3ddfcd628aa42/docs/setup)
- [Development and documentation](https://github.com/streetpea/chiaki-ng/tree/a9a2805884cfa83865fdfcc09ca3ddfcd628aa42/docs/diy)
- [Release and feature history](https://github.com/streetpea/chiaki-ng/tree/a9a2805884cfa83865fdfcc09ca3ddfcd628aa42/docs/updates)

These links identify upstream source history. Upstream installers, settings
paths, controller layouts, community contacts and release claims are not
GameRemote instructions. Current GameRemote implementation and validation are
recorded in the [release guides](release/README.md).

Legacy branded artwork has been removed from the active source asset set.
Current GameRemote documentation uses the GameRemote icon. Historical runtime
screenshots retained with the [design evidence](design/screenshots/README.md)
keep their original provenance.
